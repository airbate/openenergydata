# 科研领域：数据可信与标准生态调研

> 调研日期：2026-10-17。范围：科研数据（research data）的评测标准、工具生态与商业模式。
> 核心发现：科研领域有自己完整的标准体系（FAIR + 汇交制度 + 期刊政策），且已出现两个与我们高度相关的先例——**F-UJI**（自动 FAIR 评分，只查元数据不查内容）与 **DataSeer**（AI 数据检测，已商业化卖给出版商和资助机构）。"数据内容可信尽调"（LCL 模式）在该领域仍无产品。

---

## 一、科研领域的评测标准体系（四层）

### 1. 原则层：FAIR（国际事实标准）
**FAIR 原则**——可发现（Findable）、可访问（Accessible）、可互操作（Interoperable）、可重用（Reusable）——是全球科研数据管理的事实标准。[清华大学图书馆分析](https://lib.tsinghua.edu.cn/info/1376/6959.htm)指出我国科学数据在 FAIR 四性上均有落差，可发现性是首要短板。

### 2. 政策层（中国）：汇交制度
[国办《科学数据管理办法》（2018）](https://www.most.gov.cn/xxgk/xinxifenlei/fdzdgknr/fgzc/gfxwj/gfxwj2018/201804/t20180404_139023.html)：项目数据必须**汇交**到科学数据中心，"先汇交、后验收"。执行载体是 **20 个国家级科学数据中心**（高能物理、空间科学、基因组等），各有汇交管理办法——如[空间科学数据中心](https://www.nssdc.ac.cn/nssdc_zh/html/helpmanual.html)的汇交流程包含"标准规范审查及**质量同行评议**"。配套有《空间科学数据元数据》等国家标准。

### 3. 期刊政策层：出版商是实际的"执法者"
- 几乎所有大出版商（[Taylor & Francis](https://authorservices.taylorandfrancis.com/data-sharing/share-your-data/data-availability-statements)、[Wiley](https://authors.wiley.com/author-resources/Journal-Authors/open-access/data-sharing-citation/data-sharing-policy.html)、[PLOS](https://journals.plos.org/plosone/s/data-availability)、[Cambridge](https://www.cambridge.org/core/services/data-availability-statements)、[MDPI](https://www.mdpi.com/journal/data/instructions)）强制 **Data Availability Statement（数据可用性声明）**；
- [Nature Portfolio](https://www.nature.com/nature-portfolio/editorial-policies/reporting-standards) 对代码和数据做同行评审；**Scientific Data 的 Data Descriptor 有专门技术审评**——评审"数据文档的质量、完整性与可重用性"而非科学新颖性；
- Wiley 部分期刊要求支持数据**本身被同行评审并归档**后才予发表。

### 4. AI 科研特有层
NeurIPS D&B 赛道 datasheet + 污染缓解（见 [AI科研领域-数据可信分析.md](AI科研领域-数据可信分析.md)）：标签错误、基准污染、撤稿年增 67.8%。

## 二、已有工具与商业先例（最重要的两个）

### F-UJI——与我们最像的直接同类（但只查一半）
- [F-UJI](https://www.f-uji.net/)（EU FAIRsFAIR 项目，开源 [pangaea-data-publisher/fuji](https://github.com/pangaea-data-publisher/fuji)）：输入数据集 DOI，**自动输出 FAIR 四性评分**（REST API），基于 FAIRsFAIR 评估指标，已在 5 个认证仓储试点。
- **它查什么**：元数据合规——有没有 DOI、license、标准格式；
- **它不查什么**：数据**内容**是否可信——单位声明与数值是否相符、时间是否错位、户号是否同一人（LCL 调查的全部内容）。
- **启示**：科研领域的"自动 FAIR 评分"已被实现并成为 EU 基础设施；"自动可信尽调"还没有人做。oed check 是 F-UJI 的互补层，且方法论（证据链）更锋利。

### DataSeer——"科研数据检查能赚钱"的商业证明
- [DataSeer](https://dataseer.ai)：AI 检测论文手稿中的数据集与开放科学实践，输出合规报告；客户是**机构、出版商、资助者**（批量上传研究文本）；与 IOP Publishing 合作开发开放科学指标。
- **启示**：科研数据检查的付费方不是研究者本人，而是**出版商（投稿门禁）、资助机构（合规验证）、大学（研究诚信办公室）**——三类有预算和问责压力的机构。这与我们商业叙事的"客户分层"完全一致，且 DataSeer 证明了 B 端愿意付费。

### 其他基础设施
存储：Zenodo（CERN，免费）/ Figshare、Dryad（商业/会员）/ Dataverse（Harvard OSS）；元数据：DataCite（DOI）；AI 科研：HF Dataset Cards、cleanlab。

## 三、该领域的商业模式现实

| 角色 | 商业模式 | 案例 |
|---|---|---|
| 存储/发布平台 | 免费公共品（Zenodo）或会员制（Dryad）；规模效应归平台 | Zenodo、Figshare |
| 检查/合规服务 | **机构订阅**（出版商、大学、资助者） | DataSeer |
| 标准与评估基础设施 | 公共资助（EU FAIRsFAIR、OpenAIRE） | F-UJI |
| 研究诚信 | 捐赠/非营利 | Retraction Watch、PubPeer |
| 学术出版集团 | 出版收入反哺数据服务组合 | Digital Science（Figshare/Dimensions/ReadCube） |

**规律**：科研领域本身不直接产生订阅利润（研究者无预算），**可变现的付费方是上游机构**——出版商要投稿门禁、资助者要合规验证、大学要诚信审查。oed 若进入该领域，产品形态应是"面向机构的检查服务"，而不是面向个人的收费工具。

## 四、对 oed 的机会（科研领域四条路径）

1. **"内容可信尽调"填补 F-UJI 与 DataSeer 之间的空位**：F-UJI 查元数据、DataSeer 查论文合规，没有人查"数据本身可不可信"——LCL 调查正是这个能力的样板。可包装为 DataSeer 式的机构服务（投稿门禁/汇交验收）；
2. **期刊投稿门禁自动化**：Scientific Data 的 Data Descriptor 技术审评、NeurIPS D&B 的 datasheet 验证，都是人工流程——oed check 的自动化输出直接嵌进编辑工作流；
3. **中国汇交制度红利**：20 个国家科学数据中心"先汇交后验收"的质量审查是人工+文档审查，自动化检查工具是现成缺口（政策依据已存）；
4. **AI 科研特有检查**（污染检测、datasheet 验证）作为进阶模块，借助 [AI科研领域-数据可信分析](AI科研领域-数据可信分析.md) 中的顶会证据背书。
