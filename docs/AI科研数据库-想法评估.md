# 想法评估：「建一个 AI 科研数据库」

> 评估日期：2026-10-17。用户命题：科研领域 AI 驱动是常识，建立 AI 数据库是趋势。
> 结论先行：**趋势判断正确且政策实锤；但产品形态应从"建数据库"修正为"建数据库的可信测评层"——恰好是国家文件点名征集的，也是 oed 已完成 80% 的东西。**

## 一、趋势判断验证：对，且有政策实锤

| 证据 | 内容 |
|---|---|
| [国家数据局 2026 年 25 号文](https://www.nda.gov.cn/sjj/zwgk/zcfb/0608/20260608172117399715004_pc.html)（2026-06-08） | 《关于推进行业高质量数据集建设行动的通知》：发起高质量数据集**测评联合行动**，按标准、用**统一测评方案和工具**开展测评和封装，实现"**一次测评、全国互认**" |
| 语料基建 | [中文互联网基础语料 4.0 发布](https://www.cac.gov.cn/2026-09/16/c_1791306277101208.htm)；主流价值语料库超 300TB；中国大模型语料数据联盟（书生·万卷，OpenDataLab 为指定开源平台） |
| 学术侧 | AI 驱动科研（AI4Science）已成范式；[2026 年论文](https://arxiv.org/html/2509.06580v5)指出现有科研数据集"为人类解读优化、而非为 ML 训练优化"——正是可信化改造的需求来源 |

## 二、"建数据库"的三种形态，生死完全不同

| 形态 | 描述 | 判定 |
|---|---|---|
| ① 通用大而全 hub（论文+代码+数据+模型） | 与 HF / ModelScope / OpenDataLab / Semantic Scholar 正面竞争 | **红海死地**：网络效应已定；PWC 有 Meta 背景仍于 2025-07 关停 |
| ② 垂直域 AI-ready 数据库 | 单一行业（能源/材料/生物）的高质量数据集库 | **可行但重**：数据获取与维护成本高，且本质仍是"存储分发" |
| ③ **数据库的可信测评层** | 不存数据，给所有库里的数据发出可信档案：声明 vs 实测、来源哈希、证据链、可信评级 | **蓝海 + 政策点名 + oed 已有 80%** |

25 号文的原话是征集"**统一测评方案和工具**"——国家要的不是再建一个数据库（①②有的是人做），而是**让已有数据库里的数据可测、可信、可互认的工具与标准**。这层目前没有占位者。

## 三、与 oed 的关系：这不是新项目，是 oed 的"国家场景化"

oed 已具备形态③的全部核心件：
- `oed check`：只读、证据链、机器可读（JSON+退出码）——就是"测评工具"的本体；
- LCL 调查：一次完整的"数据集尽调"示范（发现归一化/时间错位→官方源恢复→撤回留痕）——就是"测评报告"的样板；
- 69 项测试 + CI：测评工具本身的可信性背书。

缺口只有一个：**按 25 号文的口径把检查项标准化、并绑定一个行业测评试点**。能源域是我们的样板域（数据已接入、调查已完成），天然是"行业高质量数据集测评"的第一个试点候选。

## 四、可行落地形态（如果立项）

- **形态 A「AI 科研数据集可信索引」**：登记公开 AI 数据集 → 自动跑 oed check → 产出可信档案与分级评级（类似信用评级）。填 PWC 关停后的真空，但差异化在"可信"而非"全"。
- **形态 B「行业数据集测评工具」**：对标 25 号文，做能源域高质量数据集的测评工具与方案提案，争取"一次测评、全国互认"体系中的工具供给方位置。
- **形态 C「AI 可消费出口」**：把可信档案做成 MCP server，让 agent 按"可信等级"取数——与 Precisely 等形成中立差异化。

三者共享 oed 全部资产，A→B→C 递进，单打独斗从 A 起步、B 绑政策、C 抢心智。

## 五、诚实边界

- 测评标准话语权在官方联盟（国家数据局、上海 AI 实验室等）手中，独立项目应定位"**工具与证据供给方**"，不做标准制定者；
- 索引类形态有冷启动问题（鸡生蛋），启动需绑定既有 hub（HF/OpenDataLab）而非自建门户；
- HF 等平台未来可能内置质检功能——窗口期存在，护城河在领域检查项与调查公信力。
