# 数据工程方向 Idea 池

> 用途：①标注 ★ 的是 v1/v2 功能模块，可直接吸收进 OpenEnergyData；②标注 ◎ 的是平行/赛后项目；③标注 ◇ 的是组合打法。
> 灵感来源：OpenDriveData 一等奖公式、数据要素×获奖范式、AI+治理/合成数据/具身数据饥渴三大趋势。

## 一、OpenEnergyData 的功能模块池（★ 进 v1，★★ 进 v2）

1. ★★ **合成数据增强模块**：为稀缺场景生成补充数据——热浪/寒潮极端负荷、节假日模式、光伏出力波动；统计仿真 + 轻量生成模型两条路线；隐私版输出（保统计特征不含真实住户）。对应"合成数据 2026 成主力训练源"趋势。
2. ★★ **MCP 数据问答服务**：把统一后的数据集包成 MCP server，让 Claude Code/Cursor 直接用自然语言查询（"哪栋楼夏季夜间基线漂移最大？"）。对应 MCP 工具链崛起趋势，也是你熟悉的 agent 生态。
3. ★ **质量规则市场**：YAML 规则库独立成包，社区像贡献 lint 规则一样贡献领域规则（"电热水器 >12kW 异常"），带版本与作者署名。
4. ★ **数据集发现器**：自动登记公开能耗数据集目录（元数据、许可、覆盖范围）→ 血缘图可视化，回答"这个域还有哪些数据可用"。
5. ★★ **隐私合规导出**：k-匿名聚合、差分隐私统计导出——直接对齐"数据要素×"大赛的可信数据空间叙事，给机构用户的安全出口。
6. ★ **NILM 模型动物园**：统一接口封装 3-5 个分解算法，跑通"数据→训练→评测"一键流水线（v2 扩展基准深度）。

## 二、同方向的平行/赛后项目（◎）

7. ◎ **具身轨迹评注器**：LeRobot 格式机器人操作轨迹的 LLM 自动质量评注（成功/失败/异常段标注）——具身数据饥渴是未来一年最热的数据工程赛道，AgiBot World 生态缺这类工具层；15 天做不深，适合赛后立项。
8. ◎ **政务表格质量引擎**：面向数据要素×政务场景的 LLM 数据质量工具（表格标准符合性检查、异常解释、整改建议单）——蓝本是数据要素×大赛获奖范式。
9. ◎ **数据集质量徽章服务**：给开源数据集发"质量徽章"（像 CII Best Practices badge）——扫描+评分+徽章嵌入 README，社区基建型项目。
10. ◎ **垂直域复制机**：把 OpenEnergyData 的"规格+转换器+AI评注+基准"四件套公式复制到充电桩/光伏/建筑 BMS 等域——每个域一个机会，也是主项目的长期路线图。

## 三、组合打法（◇）

11. ◇ **数据基座 × AI 编码代理**：oed 全部能力通过 CLI+MCP 暴露，演示"让 agent 自主完成一次数据接入与质量审查"——把 2026 两个最热趋势（agent 工具链 × 数据工程）缝在同一叙事里，demo 视频的差异化亮点。
12. ◇ **基座 × 大赛资源飞轮**：入围后用大赛奖励的算力/Token 跑更深的基准与规则生成，把"获奖→资源→项目升级→社区增长"写进长期发展答辩。
